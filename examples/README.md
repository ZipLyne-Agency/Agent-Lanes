# Examples

MCP client configuration for the three browser routes. Replace `/Users/you` with your
home directory; JSON and TOML configs do not expand `~`.

| File | Client |
|---|---|
| `claude-code.sh` | Claude Code (`claude mcp add`) |
| `codex-config.toml` | Codex (`~/.codex/config.toml`) |
| `mcp.json` | Cursor (`~/.cursor/mcp.json`), Claude Desktop, and other `mcpServers` JSON clients |
