# Security policy

This project lets software on your Mac drive your logged-in browser. Please report
anything that lets something other than your own agents reach the extension, the native
host, or the token, or that lets one agent reach another agent's tabs or yours.

Report privately through GitHub's **Report a vulnerability** button on the Security tab
of this repository. Please do not open a public issue for a vulnerability. We aim to
acknowledge reports within a few working days.

The security model, and what it deliberately does not cover, is in
[docs/security.md](docs/security.md).
